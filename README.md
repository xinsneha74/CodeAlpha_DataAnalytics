# Human Resources Analytics Dashboard

## Objective

Developed an interactive HR Analytics dashboard to monitor workforce performance, employee satisfaction, recruitment efficiency, and employee turnover.

## Features

* Recruitment Metrics Tracking
* Employee Turnover Analysis
* Employee Satisfaction Monitoring
* Performance Analysis
* Hiring Forecast using Predictive Analytics

## Tools Used

* Power BI
* Excel
* DAX

## Key Insights

* Identified departments with high attrition rates.
* Analyzed employee satisfaction trends.
* Forecasted future hiring requirements.
* Improved workforce planning through data-driven insights.

## Dashboard Visuals

* KPI Cards
* Bar Charts
* Pie Charts
* Line Charts
* Forecasting Visuals

## Outcome

The dashboard supports HR teams in making informed recruitment and retention decisions.
